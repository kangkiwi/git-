# 실시간 암호화폐 가격 변동 추적기

Binance 24hr Ticker API를 1초마다 호출해 USDT 마켓 코인의 가격 변동을 실시간으로 보여주는 웹 페이지입니다.

## 실행 방법
`index.html`을 브라우저로 열거나, VS Code의 **Live Server** 확장으로 실행합니다.

## 구현 기능
- **실시간 업데이트**: `https://api4.binance.com/api/v3/ticker/24hr`에 매초 GET 요청 (이전 요청이 끝나기 전엔 중복 요청하지 않음)
- **USDT 항목만 표시**: 심볼이 `USDT`로 끝나는 코인만 반영 (거래 중단으로 가격이 0인 항목은 제외)
- **검색**: 심볼 검색 (대소문자 구분 없음)
- **관심항목**: ☆ 클릭 시 LocalStorage(`favorites`)에 저장, 새로고침해도 유지
- **탭 분리**: 전체보기 / 관심항목 보기

## 추가 기능
- 상승은 빨간색, 하락은 파란색으로 표시
- 마지막 업데이트 시각 표시 및 요청 실패 시 안내 문구
- 모바일 화면에서 표 가로 스크롤
